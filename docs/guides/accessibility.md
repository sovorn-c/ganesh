# Accessibility Guide

Ganesh is designed to operate primarily within standard terminal emulators, prioritizing keyboard accessibility, non-color status differentiation, and compatibility with screen readers.

## Terminal Operation and Navigation

- **Keyboard-First Controls:** All operations can be navigated and triggered via keyboard commands.
- **Non-Color Indicators:** Status indicators do not rely solely on color cues. Textual prefixes and distinct ASCII/Unicode symbols differentiate states (e.g. `[READY]`, `[BLOCKED]`, `[READ-ONLY]`).
- **Screen Reader Support:** Clean sequential output in terminal-first workflows enables screen reader speech synthesis without graphical canvas hurdles.

## Non-Certification Notice

This guide documents the accessibility features implemented in the Ganesh terminal workspace. It does not constitute formal WCAG certification or hardware accessibility claims.
