# Release Notes

## Version 0.1.0 — Initial Local Release

This release establishes the baseline for the Ganesh local-first research supervision assistant.

### Key Capabilities

- **Durable Local Storage (E01–E02):** SQLite persistence, content-addressed artifacts, branch revisioning, and crash-resilient store reconciliation.
- **Capability-Based Authority & Policy (E03–E04):** Cryptographic capability tokens, policy permissions, monotonic withdrawal, and explicit human commitment gates.
- **Specialist Sessions & Bounded Work (E05–E06):** Controlled worker dispatch, rate and time budgets, candidate disagreement tracking, and late-output quarantine.
- **Evidence & Literature Synthesis (E07–E08):** Located evidence assertions, citation verification, review protocol versioning, and uncertainty screening.
- **Methodology & Ethics Governance (E09–E10):** Research question framing, construct mapping, activity risk registers, and ethics consultation boundaries.
- **Isolated Analysis & Study Progress (E11–E12):** Execution modes (`ask`, `approve`, `full-access`), bash guard, protocol progress, and amendment deviation tracking.
- **Traceable Writing & Terminal Workspace (E13–E14):** Attributed drafting, ranked review issues, Pi-reusing terminal workspace, and native evidence viewers.
- **Portability & Operational Reliability (E15–E16):** Canonical backup/restore, migration drills, controlled deletion tombstones, structured diagnostics, and operational runbooks.
- **Release Qualification & Distribution (E17–E18):** Adversarial test suites, competency inventories, verified support matrix, reproducible npm-pack packaging, and research-data-preserving lifecycle.

### Upgrades and Migrations

- Upgrades preserve the research project database and artifact files.
- Rollbacks require restoring from an E15 backup using the previous release tarball.
